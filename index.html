Sentinel sits between your AI coding agent and your codebase as a PreToolUse hook. Every proposed diff is checked against — patterns before it reaches disk — and when something is wrong, the agent gets a plain-English explanation injected back into its own context, so it self-corrects instead of just getting blocked.

01 — THE CORRECTION STREAM

The agent doesn't get blocked.
It gets taught.

A blocked edit with no explanation just teaches an agent to try a variation. Sentinel sends back the reasoning, the risk, and a named safer pattern — so the model rewrites the diff itself. Every case below is generated from the shipped ruleset.

03 — THE SILENT PROXY

It drops into your workflow.
Then it disappears.

It is a PreToolUse hook, not a new IDE. Claude Code hands every Write and Edit to it before the edit lands; it reconstructs the file as it will be, diffs it against what it is, and judges only the added lines.

sentinel hook --fast

Generated, not copied: the interpreter lives at .venv/bin/python on macOS and Linux and .venv\Scripts\python.exe on Windows, so install-hook writes whichever one is yours.
