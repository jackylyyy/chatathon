02 — THE CORRECTION STREAM

The agent doesn't get blocked.
It gets taught.

Standard SAST throws an alert and stops the line. Agent Conscience injects a terminal-style explanation back into the agent's own context — the reasoning, the risk, and a safer pattern. The model rewrites the diff itself, so the fix is learned, not pasted.
